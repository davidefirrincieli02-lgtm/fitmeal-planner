* setting up the local PostgreSQL database in pgAdmin
* running and testing `schema.sql` and `seed.sql`
* inserting and correcting the selected food dataset
* testing the Flask web app in the browser
* checking that the website interacts with PostgreSQL through SQL
* testing food search, meal creation, meal deletion, daily logs, and calorie targets
* editing the final source code, templates, CSS, README, E/R diagram, and SQL files
* committing the final changes to the Git repository

The final submitted repository has been reviewed by the group. The group remains responsible for the content, functionality, correctness, and limitations of the submission.
